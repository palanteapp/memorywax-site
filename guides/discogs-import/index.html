Guides / Discogs import

Bring your Discogs collection

Already keep a Discogs collection? Memory Wax can read it with your own token. It only reads. Nothing is written back to Discogs.

1. Make a personal access token

  1. On discogs.comSign in, then go to Settings → Developers and generate a personal access token.
  2. Paste it into Memory WaxSettings → “Discogs token”. Paste it and tap Save. It stays on this phone. Never paste your Discogs password here.
  3. Test the connectionTap “Test the connection”. It checks line by line: token accepted, search works, release details work, your collection is readable and how many records it found.
The token is only for this import. Deadwax matching and credits work without one, through Memory Wax’s own index of Discogs’s open data.

2. Run the import

  1. Settings → “Import from Discogs”Tap “Start the import”. You can keep using the app while it runs.
  2. Watch the progressIt reads your “All” folder, 100 records at a time, about one page a second. “Stop” ends it after the current page.
  3. DoneYou’ll see “N added · M already here”. Tap “View in Collection”.

What comes across

ImportedNot imported
Title, artists, year, first label and catalog number, formats, Discogs release and master numbers, cover image, first genre (becomes a filter), Media Condition (mapped to M, NM, VG+, VG, G+, G, F, P), and Collection Notes (become your memory, if the record has none).Sleeve condition, custom fields, folders, ratings, date added, price, and wantlists.

Imported records arrive as “Release found · Imported”. They’re Album only until you scan their labels or deadwax. Importing again adds new records and updates the rest. It never deletes anything.

3. Fill in credits

After an import, tap “Fill in credits and details for my records”. Memory Wax works through each record without credits, about one every second, using Discogs (with your token) and MusicBrainz. You can stop it any time. Otherwise credits load one record at a time as you open them.

No Discogs? Use a CSV

Settings → “Upload a CSV”. It needs a header row and a Title column. Everything else is optional. Headers are matched by how they start:

FieldHeader starts with
Title (required)title, album or release
Artistartist
Yearyear, released or date
Label, Catalog, Country, Formatlabel, cat or catalog, country, format
Barcodebarcode, upc or ean
Matrixmatrix, runout or deadwax
Conditioncondition, media condition or grade (only M, NM, VG+, VG, G+, G, F, P)
Paid, Where, Memorypaid or price; where, bought, shop or store; memory, note, notes or comment

Put the Title column before any other column whose name starts with “release”. Files separated by semicolons or tabs aren’t understood. The app’s own “Export as CSV” file can be imported back.

If something goes wrong

  • “Discogs did not accept the token.” Check it in Settings, or make a new one.
  • “Discogs is rate limiting.” Wait a minute. Discogs allows about 60 requests a minute.
  • “That doesn’t look like a Discogs personal access token.” You pasted something that isn’t a token. It should be a long string of letters and numbers.

Data provided by Discogs. Memory Wax uses Discogs’ API but is not affiliated with, sponsored or endorsed by Discogs.
